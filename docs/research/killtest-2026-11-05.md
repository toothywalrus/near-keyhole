# Kill test: can a NEAR contract arbitrate a key sale? (2026-11-05)

**Answer: yes, by a factor of about 30.** A full dispute over a real wrapped GGM node costs **9.42 Tgas**
for the whole transaction on NEAR testnet, against the 300 Tgas a transaction may carry. No fallback (attested
job, cheaper curve, host-function ECDH) is needed.

## What was measured

`contracts/killtest` does exactly what a dispute must do, logging `env::used_gas()` after each step:

1. check the revealed one-time secret against the buyer's registered x25519 key (one base-point multiplication);
2. derive the wrap key (one x25519 multiplication with the trader's ephemeral key, one SHA-256);
3. decrypt the wrapped node (three ciphers compared);
4. hash the node and walk a 16-level SHA-256 Merkle path to a root committed before the sale.

The inputs come from `tools/killtest.ts`: a real GGM tree over 2^16 slots, a real one-time key, a real wrap.
A garbage wrap was measured as well, to show the cost is the same when the proof succeeds.

Wasm: `x25519-dalek` 2 (32-bit backend) and `chacha20poly1305` 0.10 on near-sdk 5.29.1, 148,242 bytes after
`wasm-opt -Oz`. Nothing was tuned.

## What follows

- A fair exchange with no operator fits comfortably, so the design's second piece stands (`0002`).
- ChaCha20 in wasm is cheaper than SHA-256 CTR through the host. Choosing a cipher is therefore a question of
  security and wasm size, not gas (`0003`).
- Decrypting a 160-byte entry is about 0.03 Tgas, so the expensive part of a PnL fraud proof will be state reads,
  not cryptography. That number is measured separately once the contract exists (see the README).

## Reproduce

`npm run killtest` runs it in a local sandbox, free, from the checked-in `res/killtest.wasm`.
